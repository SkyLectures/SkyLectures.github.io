> - **설비 개조 없이 즉시 바꿔 생산하는 유연 생산 체계(FMS)**로 전환해야 함

## 1. 컨베이어 벨트 🡪 매트릭스 셀 생산 구조로의 전환

- **기존 직선형 컨베이어 라인의 한계 (Linear Assembly)**
    - **구조:**
        - 1 🡪 2 🡪 3 🡪 4번 설비가 일렬로 고정 연결된 구조

    - **치명적 문제:**
        - **Bottleneck 전염:**
            - 2번 설비가 고장 나거나 작업 시간이 지연되면 3, 4번 설비 전체가 멈춤

        - **혼류 생산의 한계:**
            - 공정 순서가 다른 신제품(예: 1 🡪 3 🡪 2 🡪 4$ 순서 필요)이 들어오면 기존 라인을 활용할 수 없음

- **매트릭스 셀(Matrix Cell) 생산 방식**
    - **구조:**
        - 바둑판(Grid) 형태로 가공/조립 기능별 독립된 셀(Cell A, B, C, D)들을 배치
        - 셀 사이의 물류 이동을 자율주행 로봇(AMR)이 담당

    - **장점:**
        - **공정 순서의 유연성:**
            - 주문 품목에 따라 AMR이 자재를 `Cell A ➔ Cell C ➔ Cell B` 순서로 유연하게 배달

        - **부하 분산(Load Balancing):**
            - Cell B1이 가동 중이거나 고장 나면
            - AMR이 동등한 기능을 수행하는 Cell B2로 자재를 우회 이송하여 라인 멈춤 제로화


## 2. FMS 구현의 3대 핵심 요소

- 유연 생산 시스템(Flexible Manufacturing System, FMS)
- 설비를 뜯어고치지 않고 소프트웨어와 데이터만으로 품목 전환(Changeover)을 가능하게 만드는 3대 축<br><br>

- **모듈화 설비 (Modular Hardware)**
    - **개념:**
        - 설비 단위를 기블럭(Lego Block)처럼 인터페이스와 치수를 표준화하여 설계

    - **현장 적용 예시:**
        - 로봇 체인저(Tool Changer) 기술:
            - 로봇 그리퍼(Gripper)가 부품 형상에 따라 10초 만에 자동으로 손가락 툴을 교체
        - 모듈형 금형/지그(Jig):
            - 하나의 설비 베이스 위에서 상부 지그 플레이트만 원터치로 교체하여 타 품종 가공

- **가상 레시피 관리 (Dynamic Recipe Management)**
    - **개념:**
        - 품목이 바뀔 때마다 작업자가 PLC 프로그램의 타임 차트나 온도/압력 수치를 일일이 수동 조작하지 않는 시스템

    - **현장 적용 예시:**
        - 자재가 셀에 진입할 때 바코드/RFID 태그를 읽는 순간,
            - MES/ERP 서버에서 해당 품목 전용 '공정 조건 레시피(Recipe XML/JSON)'가
            - PLC 메모리로 자동 다운로드(Download)
        - 사출/가공 조건(온도, 압력, 속도, 좌표값)이 0.1초 만에 자동 변경되어 즉시 가동

- **소프트웨어 정의 제조 (Software-Defined Manufacturing, SDM)**
    - **개념:**
        - 하드웨어의 물리적 배치를 바꾸는 대신,
        - **상위 소프트웨어 알고리즘이 로봇과 설비의 작업 역할(Behavior)을 정의**하는 개념

    - **현장 적용 예시:**
        - 똑같은 6축 관제 로봇이 오전에는 '자재 투입 및 나사 체결' 역할을 하다가,
        - 상위 OS의 제어 스크립트 전환을 통해 오후에는 '품질 검사 비전 촬상' 역할로 변신


## 3. Mass Customization (대량 맞춤 양산) 전략

- **Mass Production (대량 생산):**
    - 단가가 매우 낮으나 품목 선택지가 없음 (Ford T카 모델)

- **Customization (주문 제작):**
    - 고객 맞춤형이나 생산 단가가 비싸고 납기가 오래 걸림

- **Mass Customization (대량 맞춤 양산):**
    - **"대량 생산의 비용/속도 경쟁력" + "개인 맞춤형 주문 대응력"의 결합**
    - **대표 현장 사례 (전자/자동차 업계):**
        - **노트북/스마트폰 주문 생산:**
            - 고객이 웹사이트에서 CPU, RAM, 외관 색상, 각인 문구를 선택하면,
            - 스마트 공장의 FMS 라인으로 주문이 전송되어
            - 일반 양산품과 똑같은 속도로 자동 조립되어 24시간 내 출하

<br>

> - **유연 생산 시스템(FMS)의 핵심은 '공장의 체질을 유연하게 만드는 것'**
>   - 신제품이 나올 때마다 몇 달씩 라인을 정지시키고 억 단위의 라인 개조 공사를 하던 시대는 끝
>   - **독립된 셀(Cell) 구조와 AMR 물류, 자동 레시피 다운로드, 그리고 모듈화된 설비**를 갖출 때,
>       - 아침에는 A 제품, 오후에는 B 제품을 생산해도 생산성과 단가가 유지되는
>       - **Mass Customization 시대의 승자**가 될 수 있음
